# Recording backgrounds

All three compositions are 1920×1080, with matching SVG and PNG files. Preserve their presenter-safe areas when cropping or framing.

- `planeir-youtube-bg-wordmark-top-left-url-bottom-left.*`: normal-reading lockup at top left, website badge at bottom left; this is the app video composer's background.
- `planeir-youtube-bg-wordmark-bottom-left.*`: normal-reading lockup at bottom left.
- `planeir-youtube-bg-mirror-edit-wordmark-bottom-right-reversed.*`: **editing-only; flip back before publication**. This is deliberately reversed for a horizontally flipped edit. After flip-back, verify the final text reads normally and the mark's opening is upper-right. Never upload it as finished channel/profile artwork.

These files are generated by `npm run generate:brand`; do not redraw or hand-edit their logo geometry. External Zoom/YouTube accounts and previously downloaded/recorded media require separate updates; see `docs/newgrange-brand-rollout.md` in the repository.
