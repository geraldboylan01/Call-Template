Help someone prepare their figures.

Planeir helps people understand different routes to their financial goals. Currently available for demos only. Help the person gather their goals and figures, then review the answers in the form.

What to tell the user

Share goals and figures to request demo access. The information is saved and can be updated through a private email link while the person waits for approval. A reusable demo invitation grants access directly, with independent saved information for each participant.

Generate my analysis currently saves the approved person’s confirmation only. Analysis generation is not connected yet; this flow sends no information to an AI provider and starts no calculations. Do not promise a completed result, personal review or call from submitting the form.

Prefill the local form

Only do this when the user asks you to. Ask for estimates where needed; leave unknown figures blank. Exclude identifiers, passwords, account numbers, exact addresses and documents.

A prefill link opens the form with draft answers. Values are removed from the address bar after the form reads them. The user should check and correct the answers. The person reviews the form and chooses Request demo access to save it. Do not grant acknowledgements or submit on their behalf. Demo access is by approval or invitation; analysis generation is not connected yet.

Question guide

The fields below come from the same schema as the form. The information schema describes fields, not permission to submit. The API description currently contains no submission operations.

Your question

Shown for every application.

QuestionFieldAnswer
What do you want to understand? question Text, up to 2000 characters. Private workspace information.
Is anything coming up, and when? upcoming Text, up to 600 characters. Private workspace information.
What would a good outcome look like? goodOutcome Text, up to 1000 characters. Private workspace information.
What worries you most? worries Text, up to 1000 characters. Private workspace information.

About you

Shown for every application. Ages set the timelines for pensions, mortgages and college.

QuestionFieldAnswer
Your age household.age A whole number from 18 to 100.
Are you planning with a partner? household.partner One of: "yes" (Yes), "no" (No).
Your partner’s age household.partnerAge A whole number from 16 to 100. Only when household.partner is "yes".
Are you married or in a civil partnership? household.married One of: "yes" (Yes), "no" (No). Only when household.partner is "yes".
Do you have children? household.children One of: "yes" (Yes), "no" (No).

Children

Shown for when household.children is "yes". Their ages show when college costs start and how long they depend on you.

QuestionFieldAnswer
Age children[].age A whole number from 0 to 30.
College plans children[].collegePlan One of: "away" (Away from home), "home" (From home), "unsure" (Not sure yet). Only when topics include "education" or "whole".
Saved for them so far children[].saved A number in euro, like 35000. Only when topics include "education" or "whole".

Income

Shown for every application. Income sets your tax, your pension relief and what a lender will offer.

QuestionFieldAnswer
Your gross pay a year, before tax income.gross A number in euro a year, like 35000.
Your partner’s gross pay a year income.partnerGross A number in euro a year, like 35000. Only when household.partner is "yes".
Your work income.work One of: "employee" (Employee), "self_employed" (Self-employed), "director" (Company director), "not_working" (Not working), "retired" (Retired).
Your partner’s work income.partnerWork One of: "employee" (Employee), "self_employed" (Self-employed), "director" (Company director), "not_working" (Not working), "retired" (Retired). Only when household.partner is "yes".
Your sector income.sector One of: "public" (Public sector), "private" (Private sector). Only when income.work is "employee".
Your partner’s sector income.partnerSector One of: "public" (Public sector), "private" (Private sector). Only when household.partner is "yes" and income.partnerWork is "employee".

Lender mortgage.lender Text, up to 60 characters. Private workspace information.

Pensions

Shown for topics: retirement, mortgage, whole (or any answers given). Your pension statement has most of these. If none apply, put "pensions" in none.

QuestionFieldAnswer
Whose pension pensions[].owner One of: "you" (Yours), "partner" (Your partner’s). Only when household.partner is "yes" (otherwise the pension is the applicant's).
Type pensions[].type One of: "company" (Company pension), "public" (Public service or defined benefit), "prsa" (PRSA), "personal" (Personal pension), "bond" (Buy-out bond from an old job), "unsure" (Not sure).
Value today pensions[].value A number in euro, like 35000. Only when type is not "public".
Personal contribution pensions[].youPay A number: a percentage of salary like 5, or euro a month with youPayUnit set to "eur". Only when type is "company", "prsa", "personal" or "unsure".
Employer contribution pensions[].employerPays A number: a percentage of salary like 5, or euro a month with employerPaysUnit set to "eur". Only when type is "company", "prsa" or "unsure".
Still paying in? pensions[].contributing One of: "yes" (Yes), "no" (No). Only when type is "company", "prsa", "personal" or "unsure".
Expected pension a year pensions[].dbPension A number in euro a year, like 35000. Only when type is "public".
Expected lump sum pensions[].dbLumpSum A number in euro, like 35000. Only when type is "public".
From what age pensions[].dbAge A whole number from 50 to 75. Only when type is "public".
